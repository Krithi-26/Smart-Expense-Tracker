🚀 Node.js Backend Server Guide

Connect SpendWise to your local Node.js Express server with zero-config JSON file storage:

Step 1: Open Terminal
Navigate to this project folder in terminal or Command Prompt.
Step 2: Start Node Server
Run npm start to start the backend on http://localhost:3000.
Step 3: Connect & Sync
Ensure Node Server URL is set to http://localhost:3000 and click Connect & Sync. Your data will be safely stored in ./data/db.json!

Google Sheets Database Setup Guide

Follow these 3 simple steps to connect your Google Sheet as a live backend database:

Step 1: Open Google Sheets
Create a new blank Google Sheet named SpendWise DB.
Step 2: Open Apps Script
Click Extensions → Apps Script, clear any default code, paste the Code.gs Google Apps Script provided, and click Save.
Step 3: Deploy as Web App
Click Deploy → New deployment → Select type: Web app.
Set "Execute as" to Me, and "Who has access" to Anyone.
Click Deploy, copy the Web App URL, paste it into Settings above, and click Sync Data!
